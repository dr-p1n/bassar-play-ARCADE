BASSAR PLAY

Dread is the currency, terror the common tongue.

Three files. Free, and staying free. Each one is a way into the same place, told from a different door — a recovered build, a site nobody has walked since, a dead band with a sentence on it. None of them explains the others. They are not meant to be understood alone.

THE FILES
  • FILE 01 VOID//DRIFT A recovered build. Contents incomplete. The log fills as you go.
  • FILE 02 RECOVERED RECORDS You are walking a site nobody has walked since. Listening costs you. So does looking.
  • FILE 03 TRANSCRIPT A dead band. Something keeps tuning through it, the same way, at the same intervals.
THE RECORD

Add yourself to it.

One list, across all three files. What goes out on it are the things that never fit inside a game — the rest of the key, the unrecovered fragments, the documents the site was carrying. Nothing is for sale here, and the games stay free whether you are on the list or not.
